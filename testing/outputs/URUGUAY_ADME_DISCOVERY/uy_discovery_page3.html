    ADME_DATA

    Baje el archivo de instalación para Linux o para WIndows según corresponda:
    (19/7/2022) (LNX64) (WIN64)


     Se agrega a la aplicación de línea de comando la posibilidad de consultar códigos de medidas SCADA más generales como ser códigos de líneas. Esto permite su posterior uso para bajar medidas de flujos por las líneas.
    La aplicación de línea de comandos cmdADME_DATA tiene una configuración para bajar nids de scada, necesarios para hacer búsquedas posteriores en cmdADME_DATA.

    Si se ejecuta con el parámetro "bajarCodigosLineas", se generan tres archivos de texto, separados por tabulación, con extensión ".xlt". Esto genera los códigos scada de centrales, líneas y demandas zonales, uno por archivo.

    Sintaxis:   cmdADME_DATA bajarCodigosLineas

    A partir del código SCADA se puede modificar el archivo de parámetros (por ej. "params.txt") y volver a utilizar el programa de la siguiente manera:

    Ejemplo: ./cmdADME_DATA params.txt salidas.sas

     ***************************************
      La aplicación ADME_DATA genera ahora un archivo con extensión ".txt" en la misma carpeta de salida de datos que le servirá como parámetro para la aplicación de línea de comando.
      La sintaxis de la aplicación de línea de comandos es:
      cmdADME_DATA archi_params archi_sas [dia_desde [dia_hasta]]

      Donde: 
        archi_params debe ser el nombre completo del archivo de parámetros (como el generado pro ADME_DATA).
        archi_sas es el archivo de salida ".sas" a generar (texto plano como el que escribe ADME_DATA). 
        dia_desde es opcional y si se suministra sobre-escribe el especificado en archi_params (formato: aaaa-mm-dd)
        dia_hasta es opcional y si se suministra sobre-escribe el especificado en archi_params (formato: aaaa-mm-dd)


    (17/12/2021)   
      Motiva el cambio de versión bugfix que impedía la impresión de los valores del final del último día.

    El archivo contiene el ejecutable ADME_DATA que debe ser puesto en la carpeta:
     {$HOME}/SimSEE/bin  si su instalación es en Linux.
     C:/SimSEE/bin  si su instalación es en Windows.

    La aplicación ADME_DATA le permite bajar series diezminutales de medidas de velocidad, radiación, temperatura, etc. de las diferentes centrales de generación.

    Limitación de responabilidad: Las series no tienen ningun tratamiento ni depuración. Corresponden a los datos crudos recibidos vía el SCADA. ADME no asume ninguna responsabilidad sobre la calidad de los datos.

    Por dudas o asistencia técnica utilice el formulario de contacto.
