# South America

**[⬇ Download this folder (zip)](https://github.com/thomasdalton9/Energy/releases/latest/download/south_america.zip)**

Brazil, Colombia, Argentina, Uruguay, Ecuador and Chile power and hydro, and the South America dashboard (MASTER_SOUTH_AMERICA.py).

The zip holds this folder plus the two shared files its scripts need
(`xlsx_notes.py`, `api_keys.example.py`) at the top level. Unzip it anywhere,
keep that layout, then run the scripts from inside the `south_america` folder. For
scripts that need API keys, copy `api_keys.example.py` to `api_keys.py`
next to it and fill in your keys (never commit that file).

The zip is rebuilt automatically every time code is pushed to the working
branch (`.github/workflows/folder_downloads.yml`), so it's always current.
