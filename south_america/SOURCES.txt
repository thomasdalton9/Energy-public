EXTERNAL DATA SOURCES
----------------------

adme.com.uy
    ADME (Administración del Mercado Eléctrico, Uruguay) - generation by source
    used by: URUGUAY_ADME_DISCOVERY.py

api.cammesa.com
    CAMMESA (Argentina grid operator) API - power generation mix by fuel/technology
    used by: ARGENTINA_CAMMESA_DISCOVERY.py
    used by: argentina_generation_mix.py

ons-aws-prod-opendata.s3.amazonaws.com
    ONS Brazil open data (AWS S3) - generation by source, hydro by region
    used by: BRAZIL_ONS_HYDRO_BY_REGION.py (--out: brazil_hydro_reservoirs.xlsx, .github/workflows/brazil_hydro_reservoirs.yml)
    used by: ONS Brazil.py

pronos.adme.com.uy
    ADME Uruguay forecast/data portal - generation by source
    used by: URUGUAY_ADME.py
    used by: URUGUAY_ADME_DISCOVERY.py

servapibi.xm.com.co
    XM (Colombia market operator) API - generation by fuel, hydro reservoir storage
    used by: COLOMBIA_XM_GENERATION.py
    used by: COLOMBIA_XM_GENERATION_DISCOVERY.py
    used by: COLOMBIA_XM_GENERATION_DISCOVERY_NOPANDAS.py
    used by: COLOMBIA_XM_HYDRO.py (--out: colombia_hydro_reservoirs.xlsx, .github/workflows/colombia_hydro_reservoirs.yml)

sipub.api.coordinador.cl
    Coordinador Eléctrico Nacional (Chile) API - hydro reservoir levels (cota)
    used by: CHILE_CEN_HYDRO.py

sipub.coordinador.cl
    Coordinador Eléctrico Nacional (Chile) portal - hydro reservoir levels (cota)
    used by: CHILE_CEN_HYDRO.py
    used by: MASTER_SOUTH_AMERICA.py

visualpeb.miem.gub.uy
    MIEM / DNE Uruguay VisualPEB - monthly natural gas flows by tariff (demand by sector)
    used by: URUGUAY_GAS.py (--out: uruguay_gas_demand_by_sector.xlsx, .github/workflows/uruguay_gas.yml)

www.aic.gob.ar
    AIC (Autoridad Interjurisdiccional de Cuencas, Argentina) - hydro basin data
    used by: ARGENTINA_CAMMESA_DISCOVERY.py

www.cenace.gob.ec
    CENACE (Ecuador grid operator) - generation by source
    used by: ECUADOR_CENACE.py
    used by: ECUADOR_CENACE_DISCOVERY.py
    (ECUADOR_POWER_DAILY.py rebuilds ecuador_power_generation_daily.xlsx from ECUADOR_CENACE.py's CSV)

www.coes.org.pe
    COES (Peru grid operator) Portal de Informacion - daily generation by fuel/technology (half-hourly SCADA)
    used by: PERU_COES_GENERATION.py (--out: peru_power_generation_daily.xlsx, .github/workflows/peru_power_generation.yml)
